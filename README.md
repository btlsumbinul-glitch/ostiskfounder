# Ostisk ফাউন্ডার কনসোল

## GitHub Pages-এ পাবলিশ করা

1. GitHub-এ একটি নতুন repository বানান।
2. এই দুটি ফাইল repository-তে আপলোড করুন:
   - `index.html` (কনসোল)
   - `data.xlsx` (সব ডেটা)
3. Settings → Pages → Branch: `main` / root → Save।
4. কিছুক্ষণ পর `https://<আপনার-ইউজারনেম>.github.io/<repo-নাম>/` খুললেই ডেটা সমেত কনসোল দেখা যাবে।

## ডেটা আপডেট করা

- পেজে কিছু বদলালে তা শুধু আপনার ব্রাউজারে থাকে।
- সবার জন্য আপডেট করতে: **⬇ এক্সেল ডাউনলোড** → GitHub-এ পুরনো `data.xlsx` ফাইলটি নতুনটি দিয়ে বদলে দিন।
- অথবা সরাসরি Excel-এ `data.xlsx` এডিট করে GitHub-এ আপলোড করুন। প্রথম সারির কলামের নাম বদলাবেন না।
- অন্য কোনো Excel ফাইল হাতে তুলতে: **⬆ এক্সেল আপলোড**।
